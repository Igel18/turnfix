# Wettkampfdaten

**Wettkampfnummer** Die Wettkampfnummer. Jede Nummer sollte nur einmal vergeben werden. Die kleinstmögliche Nummer ist 1 die größtmögliche 99999.

**Bezeichnung** Die Wettkampfbezeichnung ohne den Jahrgang.

**Jahrgang** Das Feld von Jahrgang muss immer angepasst werden. Danach können sie wählen, ob sie entweder einen bis Jahrgang angeben oder eine 3 Optionen und älter, und jünger oder Jahrgangsoffen.

**Wettkampfbereich** Hier wählen sie welches Geschlecht die Starter in diesem Wettkampf haben können
