# Wettkämpfe verwalten

![](<../../.gitbook/assets/grafik (30).png>)

Im ersten Tab des Hauptfensters (Wettkämpfe) können sie Wettkämpfe anlegen, editieren und entfernen. Klicken sie dazu auf einen der 3 Buttons über der Tabelle. Zum editieren und entfernen muss ein Eintrag in der Tabelle selektiert sein.
