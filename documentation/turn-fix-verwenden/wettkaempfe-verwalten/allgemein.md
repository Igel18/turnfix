# Allgemein

<figure><img src="../../.gitbook/assets/grafik (17) (2).png" alt=""><figcaption></figcaption></figure>

**Wettkampfnummer** Eindeutige Zahl für den Wettkampf. Die kleinstmögliche Nummer ist 1 die größtmögliche 99999.

**Bezeichnung** Der Name des Wettkampfes (z.B. Gerätvierkampf w (6-7Jahre)&#x20;

**Jahrgang** Angabe der Jahrgänge die an diesem Wettkampf starten dürchen. Wird zur überprüfung der Teilnehmer heran gezogen. Das Feld von Jahrgang muss immer angepasst werden. Danach können sie wählen, ob sie entweder einen bis Jahrgang angeben oder eine der 3 Optionen "und älter", "und jünger" oder "Jahrgangsoffen" wählen.

**Wettkampfbereich** Auswahlmöglichkeit zwischen männlich, weiblich, mixed. Wird zur Überprüfung der Teilnehmer heran gezogen.&#x20;

**Wettkampftyp** Auswahlmöglichkeit zwischen "Einzelwettkampf", "Mannschaftswettkampf" und "Gruppenwettkampf" (ACHTUNG: In TurnFix 2.x wird aktuell nur der Einzelwettkampf unterstützt. ) Wählen sie Einzel- oder Mannschaftswettkampf. Bei Einzelwettkämpfen wird jeder Teilnehmer individuell bewertet. Bei Mannschaftswettkämpfen können sie entscheiden die wie viel besten Wertungen für das Mannschaftsergebnis in Frage kommen.&#x20;

**Wertungen** Anzahl der Wertungen die bei einem Mannschaftswettkampf addiert werden. &#x20;
