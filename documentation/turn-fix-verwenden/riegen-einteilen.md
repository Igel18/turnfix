# Riegen einteilen

Hier können sie die Riegen einteilen. Dazu einfach im dafür vorgesehenen Feld die gewünschte Riegennummer eintragen und mit Enter oder Pfeil-Unten-Taste bestätigen. Mit den Pfeiltasten können sie auch durch die Teilnehmer navigieren. Links erhalten sie ein Übersicht wieviele Starter sich zur Zeit in welcher Riege befinden
