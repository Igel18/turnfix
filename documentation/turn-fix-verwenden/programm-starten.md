# Programm starten

Sie starten TurnFix über einen klick auf TurnFix.exe. Das Login Fenster erscheint. Um die Einstellungen zu ändern klicken sie auf "Einstellungen". (siehe auch Einstellungen anpassen) Geben sie ihren Benutzernamen und das Passwort des PostgreSQL Useraccounts ein falls sie diesen nicht in den Einstallungen speichern wollen und bestätigen sie mit einem klick auf "Login". Es erscheinen alle Wettkämpfe die in ihrer Datenbank gespeichert sind. Um eine neue Veranstaltung zu erstellen wählen sie "neue Veranstaltung erstellen...". (siehe auch Veranstaltung erstellen) Ansonsten wählen sie ihre gewünschte veranstaltung aus und bestätigen sie mit auswählen.
