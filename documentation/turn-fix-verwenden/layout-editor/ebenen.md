# Ebenen

![](../../.gitbook/assets/grafik.png)

Mit diesen Buttons lässt sich die Ebene eines Objekts ändern. So lässt sich z.B. ein Bild in den Hintergrund legen.&#x20;

Zudem können die Objekte mittig ausgerichtet werden.&#x20;

Mit dem Drop-Down lässt sich in das Fenster zoomen.&#x20;

<mark style="background-color:red;">BUG: Die Ebenen lassen sich nicht speichern</mark>
