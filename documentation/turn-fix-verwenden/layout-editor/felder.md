# Felder

![](<../../.gitbook/assets/grafik (37).png>)

Dem Layout können folgende Felder hinzugefügt werden:&#x20;

**Datenbankfeld** Feld welches dynamisch aus der Datenbank befüllt wird (z.B. Name der Person, oder Punkte).&#x20;

**Textfeld** Statisches Textfeld (z.B. Fülltexte "hat erreicht")&#x20;

**Grafik** Bilddatei (als \*.PNG, \*.JPG) welche mit eingefügt werden kann (z.B. Logo)

**Linie** Trennlinie&#x20;
