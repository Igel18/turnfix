# Postgre SQL

In Postgre SQL müssen externe Verbindungen (von anderen Laptops) zugelassen werden.&#x20;

Hierzug muss in der Datei C:\Program Files\PostgreSQL\11\data\pg\_hba.conf die IP-Adressen des lokalen Netzwerks eingetragen werden. Siehe [https://www.postgresql.org/docs/11/auth-pg-hba-conf.html](https://www.postgresql.org/docs/11/auth-pg-hba-conf.html)
