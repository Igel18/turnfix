# TurnFix verwenden



TurnFix ist ein Programm um Wettkämpfe zu organisieren, auszuwerten und abzuschließen. Es ist hauptsächlich für Gerätturn bzw. Kunstturnwettkämpfe konzipiert. Andere Sportarten sind jedoch nicht von Grund auf ausgeschlossen, da die Disziplinen frei definiert werden können.&#x20;

Aktuell steht das Program nur auf Deutsch zur Verfügung.&#x20;
