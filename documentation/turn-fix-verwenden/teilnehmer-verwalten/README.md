# Teilnehmer verwalten

![](<../../.gitbook/assets/grafik (22).png>)

Im zweiten Tab des Hauptfensters (Teilnehmer) können sie Teilnehmer hinzufügen, editieren und entfernen. Klicken sie dazu auf einen der 4 Buttons ![](<../../.gitbook/assets/grafik (2).png>) über der Tabelle. Zum editieren und entfernen muss ein Teilnehmer markiert sein.&#x20;
