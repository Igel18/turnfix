# Veranstaltungsdaten

Wählen sie Einzel- oder Mannschaftswettkampf. Bei Einzelwettkämpfen wird jeder Teilnehmer individuell bewertet. Bei Mannschaftswettkämpfen können sie entscheiden die wie viel besten Wertungen für das Mannschaftsergebnis in Frage kommen. Geben sie als Adresse die der Halle bzw. des Veranstaltungsort an. Diese erscheint auf dem Wettkampfbericht. Zudem erscheint eine Kombination aus Halle und Ort auf allen ausdrucken. Geben sie als Veranstalter den des Wettkampfs an (z.B. Hessischer Turnverband, Turngau ...).
