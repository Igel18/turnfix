# allgemeine Einstellungen

**Disziplin** Der Name der Disziplin.

**Berechnungsformel** Die Formel die angewendet werden soll um erreichte Leistungen in Punkte umzurechnen. Für 1:1-Umrechnung 1\*x angeben. Es ist unbedingt das Rechenzeichen in Verbindung mit x anzugeben!!!

**Eingabemaske** In dieser Form werden die Leistungen erfasst

**Bereich** Für welches Geschlecht soll diese Disziplin verfügbar sein

**Sportart** Die Untersportart der Disziplin

**Versuche** Die Zahl der Versuche pro Person in dieser Disziplin.

**Icon** Das Icon das im Programm für diese Disziplin angezeigt wird

**Tastaturkürzel** Das Kürzel um eine Disziplin über die Tastatur auswählen zu können ohne in der Liste zu suchen.

**Nachkommastellen** Die Nachkommastellen auf die das Punkteergebnis gerundet werden soll.

**Einheit** Die Einheit der Leistung (z.B. m = Meter,s = Sekunde)

**Abkürzung 1** Eine sehr kurze Abkürzung für Disziplinbezeichnung z.B. auf der Ergebnisliste

**Abkürzung 2** Mittellange Abkürzung für Disziplinbereichnung z.B. auf Wettkampfbogen.

**Bahneinteilung** Ist diese Funktion aktiviert, wird auf dem Wettkampfbogen vor der Eigentlichen Liste eine Bahneinteilung generiert. (z.B. für Leichtathletik-, Schwimmdisziplinen) Die Teilnehmer werden nach der Meldeleistung sortiert.
