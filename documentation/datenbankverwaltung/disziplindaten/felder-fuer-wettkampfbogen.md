# Felder für Wettkampfbogen

![](<../../.gitbook/assets/grafik (3).png>)

Hier können die Felder eingetragen werden, die auf dem Wettkampfbogen angezeigt werden (z.B. für A-Note, B-Note, D-Note, E-Note oder Kari-Wertungen). Hinzufügen mit Plus, editieren mit Doppelklick auf Eintrag und entfernen mit Minus

![](<../../.gitbook/assets/grafik (29).png>)

1. Feldbezeichnung: Name des Feldes wie es auf den Listen erscheinen soll.&#x20;
2. Checkbox 1: EW (Endwert)&#x20;
3. Checkbox 2: AW (Ausgangswert)&#x20;
4. Checkbox 3: Anzeige (Das Feld erscheint auf dem Wettkampfbogen)



Eingestellt wurde an der Disziplin dies:&#x20;

![](<../../.gitbook/assets/grafik (2).png>)

Beim Erfassen der Leistung wird dies angezeigt (wenn Jury-Wertungen erfassen aktiv ist). Es wird jedoch nichts berechnet (TurnFix 2.x)&#x20;

![](<../../.gitbook/assets/grafik (16).png>)

Beim Erfassen der Leistung wird dies angezeigt (wenn Jury-Wertungen erfassen aktiv ist). Es wird auch berechnet:&#x20;

![](<../../.gitbook/assets/grafik (14).png>)
