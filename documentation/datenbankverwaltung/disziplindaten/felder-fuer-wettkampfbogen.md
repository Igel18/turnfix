# Felder für Wettkampfbogen

![](<../../.gitbook/assets/grafik (3) (2).png>)

Hier können die Felder eingetragen werden, die auf dem Wettkampfbogen angezeigt werden (z.B. für A-Note, B-Note, D-Note, E-Note oder Kari-Wertungen). Hinzufügen mit Plus, editieren mit Doppelklick auf Eintrag und entfernen mit Minus

![](<../../.gitbook/assets/grafik (29).png>)

1. Feldbezeichnung: Name des Feldes wie es auf den Listen erscheinen soll.&#x20;
2. Checkbox 1: EW (Endwert, der für die Plazierung herangezogen wird. Ist "Anz" ausgewählt erscheint ein Feld auf dem Wettkampfbogen. Beim Leistung Erfassen ist der Endwert immer sichtbar und wird mit dem Gerätekürzel angezeigt. ![](<../../.gitbook/assets/grafik (36).png>)&#x20;
3. Checkbox 2: AW (Ausgangswert, z.B. bei einer P8 -> 8+10=18 Punkte)&#x20;
4. Checkbox 3: Anzeige (Das Feld erscheint auf dem Wettkampfbogen und beim Leistung erfassen, wenn "Jury Wertung" ausgewählt wurde.)
