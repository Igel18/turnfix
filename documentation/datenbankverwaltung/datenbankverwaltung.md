# Datenbankverwaltung

In der Datenbank können sie alle Einträge (Teilnehmer, Vereine, Disziplinen) editieren, die für alle Wettkämpfe verfügbar sind. Die Datenbankverwaltung wird über Datenbank -> Turnerdatenbank, Datenbank -> Vereinsdatenbank oder Datenbank -> Disziplinen gestartet. Im Fenster der Datenbankverwaltung können sie über die 3 großen Buttons oben rechts zwischen den Datenbanken hin und her wechseln.
