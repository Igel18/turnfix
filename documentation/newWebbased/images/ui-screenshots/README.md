# UI-Screenshots

Die Screenshots sind nach Funktionsbereich abgelegt. Die neu einsortierten Aufnahmen stammen vom 14. Oktober 2025 und zeigen Beispieldaten; vor einer Veröffentlichung oder Verwendung für verbindliche Schritt-für-Schritt-Anleitungen den aktuellen Stand der Anwendung prüfen.

| Ordner | Inhalt |
| --- | --- |
| `overview/` | Start- und Verwaltungszentrale |
| `events/` | Veranstaltungsworkflow, Aufbau, Wettkampftag und Veranstaltungsdetails |
| `competitions/` | Wettkampfverwaltung und Wettkampfübersicht |
| `participants/` | Veranstaltungsteilnehmer |
| `jury/` | Veranstaltungs-, Riegen- und Geräteauswahl sowie Wertungseingabe |
| `results/` | Wettkampfergebnisse |
| `settings/` | Einstellungen; die Datenbankaufnahme ist nur ein internes Beispiel und sollte wegen sichtbarer Netzwerkkonfiguration nicht ungeprüft in eine Anleitung eingebettet werden |

Weitere, bereits benannte Screenshots liegen im Stammordner dieses Verzeichnisses, zum Beispiel Disziplinen, Urkundenlayouts und Medaillenspiegel.
