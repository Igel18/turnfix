# Disziplingruppen verwalten

## Übersicht

Disziplingruppen fassen mehrere Disziplinen zusammen (z.B. "Gerätturnen 6-Kampf" umfasst alle 6 Geräte). Sie dienen der Organisation und Auswertung.

## Zugriff

**URL**: `http://localhost:5173/discipline-groups`

## Funktionen

- Gruppe erstellen
- Disziplinen zuordnen
- Gruppe bearbeiten/löschen

## Beispiele

- **6-Kampf Männer**: Boden, Pferd, Ringe, Sprung, Barren, Reck
- **4-Kampf Frauen**: Sprung, Stufenbarren, Schwebebalken, Boden
- **Mehrkampf**: Alle verfügbaren Disziplinen

## Technische Details

**Datenbank-Tabelle**: `tfx_disziplingruppen`

**API**: `/api/discipline-groups`
