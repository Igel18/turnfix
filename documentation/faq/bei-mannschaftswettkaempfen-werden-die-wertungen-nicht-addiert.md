# Bei Mannschaftswettkämpfen werden die Wertungen nicht addiert

Wird bei Mannschaftswettkämpfen eine Ergebnisliste gedruckt kann es vorkommen, dass augenscheinlich nur die höchste Wertung als Ergebnis angezeigt wird oder nicht alle Ergebnisse addiert werden.&#x20;

Das kann daran liegen, dass bei dem Entsprechenden Wettkampf nur eine Wertung eingestellt ist. (Wettkämpfe -> Wettkampf ändern -> Wertungen erhöhen auf z.B. 4)
