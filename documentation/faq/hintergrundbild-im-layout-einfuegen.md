# Hintergrundbild im Layout einfügen

Im Layouteditor lassen sich Grafiken für Urkunden hinzufügen. So ist es möglich eine Urkunde ohne Vordruck auf einmal zu drucken.&#x20;

Dazu sind folgende Schritte notwendig.&#x20;

Es muss ein Urkunden Layout im PNG-Format verfügbar sein. Dieses PNG muss im Hintergrund transparent sein, damit es andere Felder nicht überdeckt!&#x20;

Dann muss der Pfad zu dem Bild im Explorer kopiert werden. Als Feld muss nun im Layouteditor eine Grafik hinzugefügt werden. Der Pfad wird nun unter Datei eingefügt, gefolgt von dem Name der Datei. (z.B.: C:\tmp\Urkunde.png). ggf. muss nun noch die Größe angepasst werden damit das Bild sichtbar wird.&#x20;
