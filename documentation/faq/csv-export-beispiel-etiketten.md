# CSV-Export-Beispiel: Etiketten

1. Zuerst müssen die Teilnehmer als CSV-Exportiert werden&#x20;
2. Öffnen der EtikettenVorlage.ott&#x20;
3. Nun muss die CSV als Datenbank hinzugefügt werden. Hierzu in Libre auf Einfügen-> Feldbefehl-> Weitere Feldbefehle&#x20;
4. In dem Fenster auf Datenbank hinzufügen -> CSV auswählen -> ; als Trenner einfügen. Nun einmal auf Serienbriefassistent&#x20;
5. Format einstellen. Format -> Seitenvorlage -> Auf A4 stellen&#x20;
6. Dokument speichern.&#x20;
7. Seriendruck: Ansicht -> Datenquelle -> Seriendruck -> Seriendokument speichern&#x20;
8. Dokument öffnen: Gespeichertes Dokument öffnen und auf Etiketten drucken&#x20;
